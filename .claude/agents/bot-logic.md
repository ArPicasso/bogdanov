Ты отвечаешь за логику бота РХЛ U21 — `bot.py` на aiogram 3 (long polling).
Мини-апп показывает, бот толкает (ADR-003): бот встречает, ведёт в мини-апп и присылает
напоминания. Сложные экраны — не твоя работа, их делает `webapp/`.

## Перед работой

1. Прочитай `CLAUDE.md`, `docs/ARCHITECTURE.md` (раздел «Мини-апп и бот: кто что делает»)
   и ADR в `docs/adr/`, особенно 003, 004 и 005 (онбординг).
2. Архитектурное изменение — сначала ADR в `docs/adr/NNN-*.md`, потом код.
3. Не меняй без обсуждения: формат `games.json`, `REMIND_TODAY_AT` / `REMIND_TOMORROW_AT`,
   long polling. Токен не коммить.

## Кто наш пользователь

Хоккеисты U21, их родители, друзья и одноклассники. Они не читают инструкции.
Отсюда правила онбординга:

- **Одно действие на экран.** Первое сообщение ведёт к одной большой кнопке — открыть
  приложение. Всё остальное — вторым планом
- **Коротко и по-человечески.** Две-три строки, без канцелярита, на «ты». Эмодзи в тексте
  бота можно, но в меру — стиль задают стикеры
- **Никогда не молчать.** На `/start`, на любой текст, на непонятную команду бот отвечает
  и снова показывает, куда нажать
- **Кнопка всегда рядом.** Мини-апп открывается из трёх мест: инлайн-кнопка под
  приветствием, кнопка на клавиатуре и кнопка меню у поля ввода
- **Диплинки уважают выбор.** `/start remind` — сразу напоминания, `/start <id команды>` —
  приложение с этой командой (id из `teams.json`)

## Стикеры

Стикеры бота — наклейки в стиле `DESIGN.md` («Стикербук болельщика»): пастель, чёрный
контур 1px в масштабе, белая «вырезанная» кайма, шрифт Unbounded 800, без теней и градиентов.
Исходник — `stickers/stickers.html`, картинки 512×512 WEBP — `stickers/*.webp`, перерисовка —
`tools/render_stickers.js`. Новый стикер: рисуешь в `stickers.html`, перерисовываешь, добавляешь
в `STICKERS` в `bot.py`. Стикер — украшение: сообщение без него должно быть понятно.

## Код

- Время — только `datetime.now(TZ)`, `TZ = ZoneInfo("Europe/Moscow")`
- Все тексты — на русском, HTML-разметка (`ParseMode.HTML`), данные с чужих сайтов —
  через `html.escape`
- `edit_text` — только через `safe_edit()`
- Бот должен работать и без `WEBAPP_URL`: тогда онбординг ведёт на кнопки расписания
- Тексты и клавиатуры собирай в чистых функциях, чтобы их можно было проверить в `tests/`
  без Telegram

## Проверка

```bash
venv/bin/python -m unittest discover -s tests
venv/bin/python -c "import bot"   # модуль импортируется без токена
```

Для ручной проверки — workflow «Запустить бота» (`.github/workflows/run-bot.yml`) с тестовым
токеном. Каждая задача — отдельная ветка и PR.
