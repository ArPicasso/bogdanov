# ADR-003. Основной интерфейс — Telegram Mini App, бот — уведомления

Статус: принято, 24.09.2026

## Контекст

Текстовый бот не показывает таблицу лиги, календарь 26 команд и карточку матча в читаемом
виде. Разделение уже описано в `docs/ARCHITECTURE.md`: бот толкает, мини-апп показывает.

## Решение

- **Мини-апп — статическая страница** (`webapp/`: HTML, CSS, JS без сборки и фреймворков).
  Данные — один файл `webapp/data/league.json` (ADR-002). Ни сервера, ни базы
- **Хостинг — GitHub Pages.** Репозиторий публичный, Pages бесплатен и даёт HTTPS, который
  Telegram требует для мини-аппов. Workflow `pages.yml` собирает данные и публикует страницу
  при пуше в `main` и по расписанию
- **Любимая команда** выбирается при первом запуске и хранится в Telegram CloudStorage
  (в браузере — в `localStorage`). Ссылка `?startapp=<id команды>` сразу открывает нужную
  команду: каждый клуб лиги может раздавать свою ссылку
- **Тема** — из цветов Telegram, с запасной светлой и тёмной
- **Бот** получает кнопку меню «Открыть» и остаётся каналом напоминаний. Адрес мини-аппа —
  переменная окружения `WEBAPP_URL`, без неё бот работает как раньше

Экраны первой версии: «Главная» (ближайший матч и последний результат своей команды),
«Календарь» (фильтры: команда, дом/выезд), «Таблица» (две конференции), карточка матча.

## Последствия

- Частота обновления данных ограничена расписанием GitHub Actions (не чаще раза в 5 минут,
  на практике с задержками). Для счёта после матча хватает. Живой счёт на этой схеме не
  сделать — для него понадобится сервер (VPS) и отдельное решение об источнике
- Pages нужно один раз включить в настройках репозитория: Settings → Pages → Source:
  GitHub Actions
- Кнопку меню в самом Telegram можно также задать через @BotFather, если бот запущен без
  `WEBAPP_URL`
