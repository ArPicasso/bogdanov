### Как устроен сайт лиги

Движок Bitrix, общий с сайтом МХЛ. URL стабильные и читаемые:

| Что | URL |
| --- | --- |
| Список клубов | `/teams/` |
| Клуб | `/teams/62551/` — «Рязань-ВДВ» |
| Календарь турнира | `/calendar/{турнир}/` — 1378 = регулярка 25/26, 1379 = плей-офф 25/26 |
| Календарь клуба | `/calendar/{турнир}/00/{id клуба в сезоне}/` — у Рязани в 25/26 это 15336 |
| Протокол матча | `/report/{турнир}/?idgame={id}` |
| Таблицы | `/standings/`, `/standings/conference/`, `/standings/divisions/` |

Id клуба в сезоне меняется каждый сезон, постоянный id — в `/teams/`.
JSON API не нашёл: всё — серверный HTML с таблицами, парсится регулярками или
любым HTML-парсером.

### Что есть в протоколе матча

Проверено на 49 протоколах (48 регулярки «Рязань-ВДВ» + 1 плей-офф):

- номер матча, дата, **время начала**, **число зрителей**
- счёт итоговый и по периодам, пометка ОТ/Б
- каждый гол: период, время, счёт, состав (равенство/большинство), автор, две передачи, **пятёрки на льду**
- штрафы: время, игрок, минуты, нарушение
- полная статистика игроков и вратарей, судьи, тренеры

Это закрывает этапы 3 и 5 целиком — счёт, таблицу, бомбардиров — без человека на арене.
Протокол публикуется после матча; чего в нём нет — событий в реальном времени.

### Онлайн

Канал клуба `@hcryazan_official`: 5,5 тыс. подписчиков, около 1 тыс. просмотров на пост,
несколько постов в день. Канал общий для клуба, основное содержание — взрослая команда
ВХЛ («практически полный стадион»). МХК — редкие посты про составы и товарищеские игры.

Что это значит для продукта:

- **Потолок МХК-бота — сотни человек, не тысячи.** Сотни на трибуне, плюс родители
  и близкие игроков на выездах

  не будет достигнут
- Если нужна аудитория в тысячи — это взрослая команда ВХЛ, а не МХК. Это развилка
  «Что значит масштабировать», и ответ на неё теперь опирается на цифры

## Что изменилось в плане

1. **Развилка после этапа 1 решена в пользу парсера.** Админка для ввода счёта не нужна.
   Нужен парсер протоколов, как только откроется `rhl.fhr.ru`
2. **Этап 2 (база) можно не торопить.** При ~300 болельщиках JSON держит; база нужна
   под протоколы и статистику, а не под нагрузку
3. **В `games.json` не хватает времени начала.** В прошлом сезоне — 17:00 в выходные,
   19:00 в будни. Для 2026/27 время появится в протоколах или на сайте РХЛ
4. **Онлайн-трансляции лиги** (`online.khl.ru`) могут закрыть push на гол без человека
   на арене. Проверить нельзя, пока хост не добавлен в allowlist сессии
