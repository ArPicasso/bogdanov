# Telegram-каналы клубов РХЛ: разведка для ленты-обозревателя

25 сентября 2026. Вопрос владельца продукта: как собрать всё, что пишут каналы клубов лиги,
отобрать нужное и показывать в мини-аппе, чтобы получился обозреватель лиги.

Проверено загрузкой публичного предпросмотра `t.me/s/<канал>` у всех найденных каналов, неделя
с 18 по 24 сентября включительно (предсезонка). Отбор «про молодёжную команду» — правилами по
ключевым словам, без ручной проверки каждого поста, поэтому цифры — порядок величины.

Особенности, которые влияют на разбор:
- Счёт пишут как угодно: «Счёт: 2:0», «🦫1:4», «1️⃣:1️⃣», «1️⃣6️⃣:🔥» — вместо цифры бывает эмодзи
- Минута — «29’» или «на 16:44». Время поста в канале — московское
- Фото и видео клубы чаще выкладывают в ВК и дают ссылку, в Telegram — подпись со ссылкой
- В каждом посте хвост ссылок «Мы в ВК | Мы в МАКС» — его надо отрезать

## Как читать каналы

| Способ | Что даёт | Ограничения | Годится |
| --- | --- | --- | --- |
| Публичный предпросмотр `t.me/s/<канал>` | Текст, дата, число фото, видео, просмотры, номер поста; листается `?before=<номер>` | Только публичные каналы, ~20 постов на страницу, разбор HTML | Да: без аккаунта и ключей, открывается с раннеров GitHub |
| Клиентский API Telegram (MTProto, Telethon) | Всё, включая медиа и реакции, посты приходят сразу | Нужен аккаунт с номером телефона, сессия — секрет, работа на сервере | Позже, если минута задержки станет важна |
| Bot API | Посты канала — только если бот там админ | Нужно согласие каждого клуба | Как партнёрство с клубом, не как основа |
| ВКонтакте, `wall.get` | Стены групп маленьких клубов | Сервисный ключ, из нашего окружения не открывается | С VPS в России, вторым этапом |

## Что это значит

1. **Обозреватель реален, но перекошен.** Четыре клуба дают больше половины постов, у шести клубов
   почти ничего. Каждому клубу равное место дают только наши данные — результаты из протоколов.
   Лента из одних каналов покажет лигу глазами «Ахмат-Гранита» и «Самары»
2. **Посты надо собирать вокруг матча, а не показывать потоком.** 98 постов по ходу за неделю —
   это не 98 карточек, а 7 карточек матчей: последний счёт и «23 поста по ходу». К матчу пост
   привязывается по дате и сопернику (варианты написания — `aliases` в `teams.json`)
3. **Каналы — ещё один живой источник.** Для предсезонки — единственный, для регулярки — третий
   после онлайна КХЛ и Фонбета (ADR-012). Счёт из поста — слой «живое», никогда не официальный
4. **Без модели не обойтись.** Категория, относится ли пост к молодёжке в общем канале, о каком
   он матче, короткий пересказ своими словами — правила справляются с третью. Модель читает пост
   и отдаёт метки и пересказ, факты на экране — только из наших данных
5. **Сам текст постов не публикуем.** Репозиторий публичный (ADR-003): сырые посты — в кэше
   сборки, в `webapp/data` — только наш пересказ, метки и ссылка на пост. Фото не берём
   (ADR-007), дни рождения не показываем: это даты рождения несовершеннолетних
